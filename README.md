# 📚 Библиотека — каталог книг

Учебный full-stack проект:

- **Бэкенд** — Node.js + Express (`server.js`), REST API
- **Фронтенд** — React + Tailwind CSS, сборка через Vite (`client/`)
- **База данных** — SQLite (`db.js`, файл `library.db` создаётся сам)

## Что умеет

**Каталог** (доступен всем, даже без входа)
- поиск по названию и автору; фильтр по жанру; «только в наличии»
- сортировка: по названию, автору, году, рейтингу, популярности
- карточка книги: обложка, описание, рейтинг, отзывы, сколько раз выдавалась

**Читатель** — вкладка «Мои книги»
- книги на руках, срок возврата, штрафы за просрочку
- продление срока (+7 дней, до 2 раз; нельзя при просрочке или если на книгу есть очередь)
- бронирование любой книги кнопкой «📌 Забронировать»:
  - книга в наличии — сразу откладывается для читателя на 3 дня, остаётся только забрать её в библиотеке;
  - книга выдана — читатель встаёт в очередь; после возврата книга откладывается для первого в очереди;
  - не забрал за 3 дня — бронь снимается, книга переходит следующему;
  - нельзя бронировать при просроченных книгах; не больше 5 книг сразу (на руках + брони)
- отзывы и оценки от 1 до 5 ★ (один отзыв на книгу, можно обновить)
- история прочитанного

**Библиотекарь**
- добавление, редактирование и удаление книг; обложка обязательна — загрузить фото с компьютера или указать ссылку
- блок «Ждут выдачи»: отложенные для читателей книги с кнопками «Выдать» и «Снять бронь»
- выдача книги читателю (отложенную книгу можно выдать только тому, для кого она отложена; видны долги читателя) и приём возврата
- вкладка «Выдачи»: на руках / просроченные / с неоплаченным штрафом / все; продление; отметка «штраф оплачен»
- вкладка «Читатели»: долги и штрафы каждого, история выдач, создание новых читателей
- вкладка «Отчёты»: итоги, популярные книги, активные читатели, жанры, выдачи по месяцам
- экспорт каталога в CSV (открывается в Excel)

**Общее**
- вход, регистрация, смена пароля (🔑); пароли хранятся как хэши scrypt
- штраф — 20 сом за каждый день просрочки (настраивается в начале `db.js`)
- авторы без книг удаляются автоматически

## Запуск

Нужен **Node.js 22.13 или новее** (в нём SQLite встроен, отдельно ставить ничего не надо).
Проверить версию: `node -v`. Скачать: https://nodejs.org

```bash
cd library-app
npm install
npm start
```

`npm start` собирает фронтенд в папку `dist/` и запускает сервер.
Откройте в браузере: http://localhost:3000

### Разработка

```bash
npm run dev
```

Откройте в браузере: **http://localhost:5173**

Команда запускает сразу два процесса: Express на порту 3000 (перезапускается при изменении файлов бэкенда)
и Vite на порту 5173 (мгновенно обновляет страницу при изменении файлов в `client/`).
Запросы к `/api` и `/covers` Vite передаёт в Express.

Если появилась ошибка `EADDRINUSE`, порт 3000 занят другим процессом, например ранее запущенным сервером:
остановите его или запустите на другом порту (PowerShell): `$env:PORT=3001; npm run dev`.

## База данных

| Таблица | Поля |
|---|---|
| authors | id, name |
| books | id, title, author_id → authors.id, year, genre, cover_url, description |
| users | id, username, name, password_hash, role (`librarian` / `reader`) |
| sessions | token, user_id → users.id, created_at |
| loans | id, book_id, user_id, issued_at, due_at, returned_at, extensions, fine_paid |
| reservations | id, book_id, user_id, created_at, ready_at (когда книга отложена для читателя) |
| reviews | id, book_id, user_id, rating 1–5, text, created_at |

Книга считается выданной, если у неё есть запись в `loans` без `returned_at`.
Базы от старых версий приложения обновляются автоматически (недостающие столбцы добавляются при запуске).

При первом запуске база заполняется примерами: книги, учётные записи, несколько выдач, бронь и отзывы.
Чтобы начать с чистой базы — остановите сервер и удалите файл `library.db`.

## API

🔓 — доступно всем, 👤 — нужен вход, 📖 — только читатель, 🔑 — только библиотекарь.

| Метод | Адрес | Доступ | Что делает |
|---|---|---|---|
| POST | `/api/register` | 🔓 | регистрация читателя `{ username, name, password }` |
| POST | `/api/login` | 🔓 | вход `{ username, password }` |
| POST | `/api/logout` | 🔓 | выход |
| GET | `/api/me` | 🔓 | текущий пользователь или `null` |
| POST | `/api/password` | 👤 | сменить пароль `{ oldPassword, newPassword }` |
| GET | `/api/books?q=&genre=&available=1&sort=` | 🔓 | список книг; `sort`: title, author, year, rating, popular |
| GET | `/api/books/:id` | 🔓 | книга с отзывами (+ очередь и история для библиотекаря) |
| POST | `/api/books` | 🔑 | добавить `{ title, author, year, genre, cover_url, description }` (обложка обязательна) |
| POST | `/api/covers` | 🔑 | загрузить фото обложки `{ data: 'data:image/jpeg;base64,…' }` → `{ url }` |
| PUT | `/api/books/:id` | 🔑 | изменить (можно часть полей) |
| DELETE | `/api/books/:id` | 🔑 | удалить (только если книга не выдана) |
| POST | `/api/books/:id/issue` | 🔑 | выдать `{ userId, days }` (по умолчанию 14 дней) |
| POST | `/api/books/:id/return` | 🔑 | принять возврат; в ответе `next` — следующий в очереди |
| POST / DELETE | `/api/books/:id/reserve` | 📖 | забронировать / отменить бронь |
| GET | `/api/reservations` | 📖 | мои брони: место в очереди или «отложена до …» |
| GET | `/api/holds` | 🔑 | книги, отложенные для читателей и ждущие выдачи |
| DELETE | `/api/reservations/:id` | 🔑 | снять бронь читателя |
| POST | `/api/books/:id/reviews` | 📖 | отзыв `{ rating, text }` (повторно — обновляет) |
| DELETE | `/api/reviews/:id` | 👤 | удалить свой отзыв (библиотекарь — любой) |
| GET | `/api/loans?active=1` | 👤 | выдачи со штрафами: библиотекарь — все, читатель — свои |
| POST | `/api/loans/:id/extend` | 👤 | продлить выдачу |
| POST | `/api/loans/:id/pay` | 🔑 | отметить штраф оплаченным |
| GET / POST | `/api/readers` | 🔑 | читатели со сводкой / создать читателя |
| GET | `/api/readers/:id/loans` | 🔑 | история читателя |
| GET | `/api/reports` | 🔑 | данные для отчётов |
| GET | `/api/export/books.csv` | 🔑 | каталог в CSV |
| GET | `/api/genres`, `/api/stats`, `/api/config` | 🔓 | жанры, статистика, настройки штрафов |
